# Student Management CLI

A beginner-friendly Python command-line project for keeping a simple in-memory list of students and their marks.

## Features

- Add a student and their marks
- View all students
- Search for a student by name (case-insensitive exact match)
- Delete a student by name
- Update a student's marks
- Calculate the average marks
- Navigate using a simple command-line menu
- Choose a specific record when multiple students have the same name

## Requirements

- Python 3
- No third-party packages are needed

## Run the project

From this directory, run:

```bash
python app.py
```

Student data is stored in memory while the program is running and is cleared when you exit.
