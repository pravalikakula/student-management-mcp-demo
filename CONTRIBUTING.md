# Contributing

Thanks for your interest in contributing to the Student Management CLI! Contributions that improve the project while keeping it clear and beginner-friendly are welcome.

## Getting started

1. Fork the repository and clone your fork.
2. Make sure Python 3 is installed. This project has no third-party dependencies.
3. Run the program with `python app.py` to try the command-line menu.

## Making a change

1. Create a branch for your change.
2. Keep changes focused and use clear names and straightforward Python so the project remains approachable for beginners.
3. If you change how a feature works, update the README as needed.
4. Test your change by running the program and checking the relevant menu options, including appropriate empty-list or invalid-input cases.
5. Review your diff to ensure it contains only the intended changes.

## Submitting a contribution

Push your branch to your fork and open a pull request against the repository's `main` branch. In the pull request description, explain what changed and how you tested it. Be open to feedback and make any requested improvements in follow-up commits.
